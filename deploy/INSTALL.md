# Установка информационной панели на сервер

Инструкция для того, кто настраивает сервер (IT-специалист). На всё уходит около 30 минут.

## 1. Что нужно заранее

| Что | Подробности |
|---|---|
| Сервер (VPS) | Ubuntu 22.04 или 24.04, 1 ядро, 1–2 ГБ памяти, 10 ГБ диска. Лучше с размещением в России. |
| Домен | Например `лицей-интернат24.рф`. Для панели удобно взять поддомен: `табло.лицей-интернат24.рф`. Домен оформляйте на лицей. |
| Доступ к серверу | SSH под root (логин и пароль или ключ присылает хостер). |
| Файл расписания | Excel `.xlsx` со школьными листами «Расписание», «Звонки», «Замены». Нужен только для первой загрузки; дальше расписание правится в админке. |

## 2. Домен

В кабинете регистратора добавьте для поддомена запись типа **A**, значение — IP-адрес сервера. Кириллические имена регистратор переводит в служебный вид сам. Запись обновляется от нескольких минут до пары часов. Без неё HTTPS-сертификат не выпустится.

## 3. Установка

С компьютера отправьте архив проекта на сервер и запустите установку:

```bash
scp school-board-*.tar.gz root@IP-СЕРВЕРА:/root/
ssh root@IP-СЕРВЕРА
mkdir -p /root/school-board && tar -xzf school-board-*.tar.gz -C /root/school-board
bash /root/school-board/deploy/install.sh табло.лицей-интернат24.рф
```

Скрипт сам:
- ставит Node.js 22 и Caddy (HTTPS-сертификат выпускается и продлевается автоматически);
- кладёт программу в `/opt/school-board`, данные — в `/var/lib/school-board`;
- включает автозапуск (после сбоя питания панель поднимается сама);
- включает еженедельную резервную копию (воскресенье, 03:30);
- открывает порты 22, 80 и 443 (если SSH у вас на другом порту, запускайте с ключом `--no-firewall`).

В конце он печатает адреса и **логин и пароль первого директора**. Пароль нужно записать: при первом входе система потребует его сменить.

Если репозиторий Node.js недоступен с вашего сервера, скачайте с nodejs.org архив `node-v22.*-linux-x64.tar.xz`, положите его на сервер и запустите так:
`NODE_TARBALL=/root/node-v22.tar.xz bash /root/school-board/deploy/install.sh ваш.домен.рф`

## 4. Первый вход и настройка

1. Откройте `https://ваш.домен/admin`, войдите как `director`, смените пароль.
2. «Пользователи» → создайте IT-администратора и завуча. Система выдаёт временный пароль, человек меняет его при первом входе.
3. «Расписание» → загрузите файл `.xlsx`, проверьте предпросмотр и нажмите «Записать расписание». Дальше уроки, звонки и замены правятся прямо в админке.
4. «Постеры и ролики» → загрузите материалы (JPG, PNG, PDF, MP4 до 30 МБ).

Роли: **директор** — всё; **IT-администратор** — пользователи, настройки, экраны, материалы, расписание; **завуч** — материалы, расписание, замены, объявления, экраны; **просмотр** — обзор и журнал.

## 5. Экран в холле

Адрес для телевизора: `https://ваш.домен/tv`. Страница сама обновляется, работает без интернета на последних данных и сама восстанавливается после перебоев.

**Важно про Apple TV.** По имеющимся сведениям, на Apple TV нет браузера Safari и нет встроенного веб-компонента для сторонних приложений, поэтому открыть там сайт напрямую, скорее всего, не получится. Проверьте на вашей модели и версии tvOS до покупки чего-либо. Если браузера нет, подойдёт один из вариантов:

| Вариант | Надёжность | Примерная стоимость | Комментарий |
|---|---|---|---|
| Мини-ПК или Raspberry Pi 4/5 с Chromium в режиме киоска | высокая | от нескольких тысяч до 10–15 тыс. ₽ | Лучший вариант: включается вместе с ТВ, сам запускает страницу. |
| Android TV-приставка или Fire TV с браузером в режиме киоска | средняя | 3–6 тыс. ₽ | Нужно приложение-киоск и отключённый сон. |
| Apple TV + AirPlay с постоянно включённого iPad или Mac | низкая | зависит от устройства | Зависит от второго устройства и сети, для постоянной работы не рекомендую. |
| Встроенный браузер Smart TV | средняя | 0 ₽ | Зависит от модели, видео и автозапуск работают не везде. |

Запуск на Linux-мини-ПК (Chromium в режиме киоска):

```bash
chromium-browser --kiosk --noerrdialogs --disable-infobars --autoplay-policy=no-user-gesture-required https://ваш.домен/tv
```

Добавьте эту команду в автозапуск пользователя и отключите энергосбережение экрана.

## 6. Обновление программы

Распакуйте новый архив поверх (в ту же папку) и снова запустите `install.sh` без аргументов. Данные, пользователи и логотип сохраняются.

## 7. Резервные копии и восстановление

Копии лежат в `/var/backups/school-board`, хранятся 8 последних. Вручную: `sudo -u board node /opt/school-board/scripts/backup.js` (с переменными из `/etc/school-board.env`).
Копии содержат хэши паролей, храните их в защищённом месте и не отправляйте по почте.

Восстановление:

```bash
systemctl stop school-board
tar -xzf /var/backups/school-board/school-board-ГГГГ-ММ-ДД.tar.gz -C /var/lib/school-board
chown -R board:board /var/lib/school-board
systemctl start school-board
```

## 8. Если что-то не работает

| Симптом | Что смотреть |
|---|---|
| Сайт не открывается по HTTPS | Запись A у регистратора указывает на IP сервера? `systemctl status caddy`, `journalctl -u caddy -n 50` |
| Панель не отвечает | `systemctl status school-board`, `journalctl -u school-board -n 50` |
| Забыли пароль | Другой директор или IT-администратор сбрасывает его в «Пользователи». Если доступа нет ни у кого: `set -a; . /etc/school-board.env; set +a; cd /opt/school-board && sudo -u board --preserve-env node --disable-warning=ExperimentalWarning scripts/reset-password.js director` — напечатает новый временный пароль. |
| Экраны показывают старое расписание | «Экраны» в админке: видны ли телевизоры на связи. Нажмите «Обновить все экраны». Если экран давно не выходил на связь, проверьте интернет и что телевизор открыт на адресе `/tv`. |
| Логотип | Положите `logo.svg` или `logo.png` в `public/brand/` проекта и запустите `install.sh` заново. |

Настройки сервера (порт, адрес, папка данных, часовой пояс): `/etc/school-board.env`, после правки — `systemctl restart school-board`.
