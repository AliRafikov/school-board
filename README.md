# Цифровая информационная панель школы

Расписание, замены и объявления из админки → экран для телевизора (`/tv`), страница для учеников (`/`) и админка для сотрудников (`/admin`).
Нужен только Node.js 22 или новее. Внешних зависимостей нет (по желанию: `npm i sharp` — тогда картинки сжимаются до 500 КБ).

## Запуск
```bash
npm install   # один раз: ставит sharp, он сжимает картинки
npm start
```
При первом запуске создаётся пользователь `director`; временный пароль записывается в файл `data/first-admin-password.txt` (в консоль не печатается). Войдите на `/admin`, пароль нужно сменить сразу: после смены файл удаляется.

Переменные окружения (все необязательны): `PORT` (3000), `DATA_DIR` (папка с данными), `INITIAL_ADMIN_PASSWORD` (пароль первого директора вместо случайного), `TZ_NAME` (начальные значения; потом всё меняется в админке → Настройки).

## Страницы
| Адрес | Для кого | Что |
|---|---|---|
| `/tv` | телевизор | таблица замен или расписание всех классов, звонки, объявления на боковой полосе; постеры и видео — на весь экран |
| `/` | ученики, родители | расписание по классу, замены, звонки |
| `/admin` | сотрудники (по паролю) | обзор, журнал, постеры и ролики, экраны, пользователи, настройки |

## Роли
| Роль | Права |
|---|---|
| Директор | всё |
| IT-администратор | пользователи, настройки, экраны, файлы, расписание, журнал (директоров менять не может) |
| Завуч | файлы, расписание, замены, объявления, срочные сообщения, обновление экранов, журнал |
| Помощник | объявления, постеры и видео (публикует сам). Без срочных сообщений, замен и расписания |
| Просмотр | обзор и журнал |

Пароли хранятся хэшем (scrypt). Сессия — защищённая cookie на 14 дней. После 5 неверных паролей логин блокируется на 10 минут. Временные пароли обязательно меняются при первом входе.

## Telegram-бот для сотрудников
Работает, если задан `TG_BOT_TOKEN`; аккаунт привязывается в админке («Пользователи» → «Привязать Telegram»).
- **Фото → постер.** Пришлите боту фото: оно сразу встаёт на весь экран. Подпись — название. Кнопки «В центр экрана» и «Убрать» (помощник убирает только свои).
- **Добавить замену.** Дата → классы → урок → «кабинет, учитель» одним сообщением; «отменён» отменяет урок.
- **Срочные сообщения, статус экранов, замены на сегодня** — как раньше.
- **Напоминания.** Тревога висит больше 30 минут; после 16:00 нет замен на завтра; постер или объявление завтра истекает; экран не на связи 15 минут. Ночью (до 9 и после 20 по Москве) не беспокоят.

## Расписание, замены, объявления
Всё редактируется в админке, Google не нужен.
- **Расписание** — раздел «Расписание». Файл `.xlsx` со школьными листами «Расписание», «Звонки», «Замены» загружается один раз для старта. Перед записью система показывает предпросмотр: сколько уроков, что найдено и что стоит проверить, и список того, что изменится («было → стало»). Записывает только после нажатия «Записать». Даты, которые Excel превратил из времени (`12.10` → 12 октября), система исправляет сама.
- **Уроки по классам** — выбираете класс и день, правите предмет, учителя и кабинет. Каждое сохранение попадает в журнал и (если отмечено) подсвечивается на экране.
- **Звонки и перемены** — время уроков, завтрак и обед (отметьте «перемена»).
- **Замены** — дата, уроки, классы через запятую, предмет, кабинет, учитель, кого заменяют. Одна запись создаёт строку для каждого класса.
- **Объявления** — текст для центра экрана, длительность, приоритет, даты показа.

Каждое изменение пишется в журнал: что, где, «было → стало», кто и когда.

## Показ на ТВ
Таблица на `Секунд на экране` (по умолчанию 45), затем один постер или ролик на весь экран, затем снова таблица. На перемене ролик не запускается, если не успеет закончиться за 20 секунд до звонка. Материалы с отметкой «только на переменах» не показываются во время урока. Видео идёт без звука (требование Safari). Экран работает без интернета на последних сохранённых данных; кнопка «Обновить все экраны» в админке перезагружает все экраны.

## Логотип и цвета
Положите `public/brand/logo.svg` (или `logo.png`) — он появится на экране ТВ, в админке и на странице входа. Цвета админки меняются в `public/admin.css` (`--brand`, `--brand-ink`), цвета ТВ и страницы учеников — в `public/style.css`.

## Данные и копии
Всё лежит в папке `data/`: `app.db` (пользователи, журнал, файлы), `media/` (загруженные файлы). Резервная копия — копирование этой папки.

## Проверка
```bash
DATA_DIR=/tmp/t INITIAL_ADMIN_PASSWORD=Start12345 PORT=3222 node server.js &
BASE=http://localhost:3222 PASS=Start12345 node test/api.test.js
```
(тест рассчитан на чистую базу).
